# Xanda — site para GitHub Pages

Este site é estático. A página de entrada é `index.html`, na raiz do repositório. Os links e arquivos locais usam caminhos relativos para funcionar também em endereços como `https://usuario.github.io/nome-do-repositorio/`.

## Publicar

1. Envie os arquivos deste diretório para um repositório no GitHub, incluindo `.nojekyll`.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch que contém os arquivos (normalmente `main`) e a pasta **/(root)**. Clique em **Save**.

O GitHub Pages exibirá o endereço publicado na mesma tela. Consulte a [documentação oficial sobre a origem de publicação](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) se precisar alterar essa configuração.

O formulário de contato monta a mensagem e abre o WhatsApp da Xanda com o texto pronto para envio; não envia dados a um servidor.
